# 课程复习资料

从学习通已有的课程列表选一门课，工作台把章节要点、作业题和课程资料摘录排成一份复习指南，保存为 Word 和 PDF。

1. 在「设置」选择 AI 来源。使用 ChatGPT 时从「使用 ChatGPT 继续」打开官方授权页，允许使用套餐用量后选择可用模型。也可使用已配置的兼容服务。同步学习通登录状态，或在「复习资料」刷新课程。
2. 选择课程和保存位置，点击「用 AI 生成 Word 和 PDF」。后台任务支持停止。
3. 生成后点击「打开 Word」或「打开 PDF」。课程读取遇到限制时，可展开「读取详情」，文档末尾也会列出缺项。

工作台在点击生成后才读取所选课程正文，分批将可用文字交给已配置的模型。进入页面、切换课程和刷新列表不会生成文件或备份原始资料。模型配置缺失、请求失败或回复无法与条目对应时，保留失败说明并停止导出。模型可将原文不足的条目标为待查。

| 内容 | 收录范围 |
| --- | --- |
| 章节 | 课程目录及可访问的章节文字。页面只提供附件时，从能匹配且已取得正文的附件中提炼。锁定、纯视频、音频或图片内容可能只有标题。 |
| 作业 | 作业列表和已有已提交记录中可读取的题目。待作答等条目保留名称与状态，导出不创建作答记录。图片用文字占位，缺少可读正文的嵌入附件保留文件名。 |
| 资料 | 教师开放的资料及子目录。优先读取有权限下载的文档文字，每文件限 12 MiB。无下载权限、扫描件、超限或未支持的格式可保留索引。 |

导出按课程分目录，每次生成新的文件夹。未完成的转换不会留下半套文件。复习任务从所选课读取数据，在任务记录中保留状态、数量和文件路径。文档来源链接会去掉访问签名，部分必须回到学习通课程中打开。同一份 Word 在不同阅读软件里可能分页不同，PDF 为固定版式。

`libreoffice-writer` 用于 PDF 转换，建议安装 `fonts-noto-cjk` 保证中文排版。`poppler-utils` 用于从已有 PDF 取正文。旧版 DOC/PPT 取文字可用 `antiword` / `catdoc`，也可由 Bubblewrap 隔离的 LibreOffice 读取。
