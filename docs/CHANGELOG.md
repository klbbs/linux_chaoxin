# 更新记录

## 0.5.2 · 2026-11-19

- 新增 ChatGPT 官方账号授权。符合条件的账号可授权本应用使用套餐用量，工作台按账号列出可用模型。
- 按需复习和 AI 解题可使用 ChatGPT 账号，兼容 API Key 配置仍可单独选择。

## 0.5.1 · 2026-11-19

- 复习资料只在点击生成时读取课程，并使用已配置的 AI。AI 未配置或整理失败时停止导出。
- 设置页新增 OpenAI 官方 GPT 预设，默认 `gpt-5-mini`。课程整理支持官方 Responses API。

## 0.5.0 · 2026-11-19

- 新增「复习资料」，读取学习通课程章节、作业和资料，生成 Word 与 PDF。
- 将抓取、摘要、文档排版和 GTK 页面拆成独立模块。导出可停止，支持失败原因和分项统计。
- 复习默认用本机提炼正文，可选将课程文本交给已配置的模型整理。无正文或权限受限的条目在文档中标注。

## 0.4.2 · 2026-11-11

- 提取作业题干/选项图片并保留对应关系，覆盖纯图片、懒加载、公式图和srcset；使用现有会话限量下载到私有缓存。
- 将实际图片字节直接发给图像模型，无需OCR；工具续轮、关闭联网、预搜索和Responses保留图片，不支持图片时不降级为纯文字。
- 作业页增加题图预览、载入/发送数量和失败说明；缺图、缓存变化、未完整发送或提交前图片变化时停止写入。
- 增加本地HTTP多模态字节测试及缓存、解析、预览和提交拦截测试；不调用用户付费API。

## 0.4.1 · 2026-11-11

- 修复保存联网布尔开关及整数设置误用 `.strip()`，导致AI连接测试尚未请求就报错的问题。
- “允许联网”由模型决定是否使用，未调用标为自身知识回答；默认联网改为由模型调用搜索工具，另支持Responses原生web_search；保留显式预搜索兼容选项。
- 显示实际搜索调用状态及可点击来源，模型没有调用工具不会伪报联网。
- AI连接测试结果在设置页直接显示，失败不再显示为任务完成成功；连接测试不触发搜索。

## 0.4.0 · 2026-11-11

- 自动发现本机Firefox与原后端的学习通有效会话，隔离验证后同步；保留原文件，不要求在工作台输入密码。
- 作业页改为选择课程、读取学习通实际作业列表、选择作业后读题；链接和账号密码移到备用入口。
- 修复下拉控件及弹出选项在深色系统主题下难以辨认的问题，统一白底黑字。
- 安卓「学习通2.0」保留为待用户审阅批准后的需求，本次不开发、不安装、不改变手机权限。

## 0.3.0 · 2026-11-10

- 签到改为活动选择、按类型补充信息、核对提交三步；新增活动筛选、时间/人数概览与已结束拦截。
- 增加地图搜索、候选地点、拖动缩放、点选和坐标系检查；位置确认与实际提交分开。
- 增加本机常用位置、九宫格手势、二维码输入校验和最近80条签到历史。
- 参考用户指定微信小程序的可见交互；真实数据仍直接连接学习通，不使用小程序服务接口。
- 用学习通真实会话只读核对活动字段；线上签到提交尚未逐类验证，详见 [接口依据](ATTENDANCE-API.md)。

## 0.2.0 · 2026-11-10

- 默认入口升级为独立GTK工作台：课程后台、作业AI、签到、手机控制、设置与任务记录。
- 增加独立Python3.13后端桥接，保留原命令行项目及私有数据隔离。
- 增加联网检索、模型API配置、结构化解题、编辑、保存和显式正式提交。
- 增加课程计划/执行、测验串接、回读核对与未支持任务提示。
- 增加按活动参数提交签到和手机预览/点击/滑动/按键。
- 增加取消、父进程退出清理、同目标写任务去重、私有配置及日志脱敏。
- 新增固定源码校验的后端安装器和依赖锁定清单；旧Waydroid入口通过 `--legacy-launcher` 保留。
- 独立兼容模式问题仍未解决；真实线上写操作及AI密钥联调尚未执行，详见 [功能边界](FEATURES.md)。
